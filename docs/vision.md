# 🌸 PokéStudio da Lori

> A companheira para decisões inteligentes no Pokémon GO.

## Visão

O PokéStudio nasceu para resolver um problema simples: evitar que o treinador precise abrir diversos sites para decidir se um Pokémon vale investimento.

Em poucos segundos, a aplicação deve responder perguntas como:

- Vale a pena guardar?
- Vale investir Poeira Estelar?
- Vale usar Rare Candy?
- Vale usar Elite TM?
- Qual o PC do Hundo?
- Qual o melhor moveset?
- Quais são suas fraquezas?
- Qual Mega utilizar contra ele?

O objetivo não é ser mais uma Pokédex.

O objetivo é ser uma ferramenta de apoio à decisão para jogadores de Pokémon GO.

## Missão

Centralizar informações relevantes sobre qualquer Pokémon em uma única tela, de forma rápida, organizada e intuitiva.

---

## Princípios

- Simplicidade acima de tudo.
- Interface limpa.
- Poucos cliques.
- Informação confiável.
- Dados voltados para tomada de decisão.
- Nada de informações desnecessárias.

---

## Pergunta que o PokéStudio responde

> "Acabei de capturar esse Pokémon. O que devo fazer com ele?"
