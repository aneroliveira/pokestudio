# Roadmap

## Visão do Produto

O PokéStudio da Lori é uma aplicação web criada para auxiliar jogadores de Pokémon GO na tomada de decisões estratégicas.

O objetivo é reunir, em uma única interface, todas as informações relevantes para responder rapidamente perguntas como:

- Vale investir nesse Pokémon?
- Qual é o CP perfeito (100%)?
- Vale usar Doce Raro?
- Vale Elite TM?
- É útil em Raid?
- É útil contra a Equipe GO Rocket?
- Vale maximizar?
- Qual Mega utilizar contra ele?
- Quais são suas fraquezas?

O foco não é substituir uma Pokédex tradicional, mas reduzir o tempo necessário para tomar decisões dentro do jogo.
