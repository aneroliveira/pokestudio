# Banco de Dados

## Objetivo

Criar uma base de dados própria contendo informações úteis para tomada de decisão.

A ideia não é replicar a PokéAPI.

O objetivo é enriquecer os dados.

---

## Modelo

Cada Pokémon possuirá:

### Identificação

- Número
- Nome
- Região
- Tipos

---

### Classificação

- Tier
- Prioridade
- Vale investimento

---

### Utilização

- Raid
- Rocket
- PvP
- Ginásio
- Mega

---

### Hundo

- Pesquisa
- Raid
- Weather

---

### Quase Hundos

- 98%
- 96%

---

### Moveset

Fast

Charged

Elite TM

### Counters

Melhores Megas

### Evolução
